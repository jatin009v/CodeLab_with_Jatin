# 🚀 CodeLab by Jatin

### Learn Data Structures & Algorithms Visually, Step by Step

**CodeLab** is an interactive Data Structures and Algorithms (DSA) learning platform that helps developers understand complex algorithms through animated visualizations, step-by-step explanations, pseudocode, and interactive examples.

The goal of CodeLab is to make learning algorithms easier, more engaging, and more visual.

Instead of only reading theory, users can explore how algorithms work through interactive 2.5D visualizations.

---

## ✨ Features

- **Interactive Algorithm Visualizations** – Understand algorithms using animated 2.5D diagrams.
- **Step-by-Step Learning** – Learn each algorithm through simple, structured steps.
- **86 Lessons Across 14 Chapters** – Explore a structured DSA learning curriculum.
- **Pseudocode Explanations** – Follow highlighted pseudocode alongside visualizations.
- **Light & Dark Mode** – Switch between themes for a comfortable learning experience.
- **Smart Search** – Quickly find algorithms using `Ctrl + K` or `Cmd + K`.
- **Progress Tracking** – Save learning progress automatically using browser local storage.
- **Keyboard Navigation** – Navigate lesson steps using arrow keys.
- **Responsive Interface** – Access the platform across different screen sizes.
- **Smooth Animations** – Visualize how data structures and algorithms change at each step.

## 💻 Getting Started

Follow these steps to run CodeLab on your local machine.

### 1. Clone the Repository

```bash
git clone https://github.com/jatin009v/CodeLab_with_Jatin.git
```

### 2. Open the Project Folder

```bash
cd CodeLab_with_Jatin
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local address displayed in your terminal, usually:

http://localhost:5173

### 5. Build for Production

```bash
npm run build
```

### 6. Preview the Production Build

```bash
npm run preview
```

**Requirements:** Node.js 20 or higher and npm.

## 🎯 How CodeLab Works

CodeLab uses an interactive step-based learning approach.

**Step 1: Choose an Algorithm**

Select a topic from the course sidebar.

**Step 2: Explore the Visualization**

Watch animated diagrams illustrating how the algorithm works.

**Step 3: Understand the Logic**

Read explanations and follow the corresponding pseudocode.

**Step 4: Navigate Through Steps**

Use the Next and Back buttons or keyboard arrow keys to explore the algorithm.

**Step 5: Track Your Progress**

Your lesson progress is saved automatically in your browser.
